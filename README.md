# Irene, game artist: portfolio

A React site (Vite + TypeScript) showing three games and one learning project.

## Run it

Needs Node.js 20 or newer.

```
npm install
npm run dev
```

Then open the address it prints (usually http://localhost:5173).

## Publish it

```
npm run build
```

Upload the `dist` folder to any static host (GitHub Pages, Netlify, Vercel).

## Where things are

- `src/content.ts`: all game text, roles, the About paragraphs and contact links.
- `src/pages/`: one file per page.
- `public/img/`: the art and screenshots. `public/lottie/`: the animations.
